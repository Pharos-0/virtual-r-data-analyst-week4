# Data

- `raw/Telco-Customer-Churn.csv` – the unmodified IBM Telco Customer Churn file (7,043 rows × 21 columns, MD5 `3b0bfab28a8101b4e4fdd08025a5c235`).
- `raw/LICENSE-Apache-2.0_IBM.txt` – the Apache License 2.0 of the IBM repository the file comes from. The data are redistributed here under that licence, with attribution to IBM.
- `processed/telco_clean.csv` – the cleaned data written by `R/02_data_cleaning.R` (no missing values; categorical fields stored as text in the CSV and as factors with a set level order in the `.rds` file, which is regenerated by the scripts and not committed).

If the raw file is deleted, `R/01_data_import.R` downloads it again from:

https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Source repository: https://github.com/IBM/telco-customer-churn-on-icp4d (IBM). The variables are described in the data dictionary written by `R/01_data_import.R` to `outputs/tables/w1_data_dictionary.csv`.
